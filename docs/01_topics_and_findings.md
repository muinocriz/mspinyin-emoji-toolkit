# 主题与当前结论

- **内置 Emoji 映射**：本机样本的直接拼音→Emoji 记录可在 `ChsPinyinUDP.lex` 中解析。
- **Win+. 与微软拼音分离**：Emoji 面板的语言搜索资源和微软拼音 UDP 不是同一份数据。
- **内容年代**：样本对 Unicode 10 / Emoji 5（2017）覆盖很强，而 Unicode 11（2018）以后新增 Emoji code point 未发现进入 UDP。
- **双向转换**：完整 3099 条样本可 LEX→CSV→LEX 且未修改时逐字节一致。
- **多 Emoji text**：`text` 是 UTF-16LE 字符串，因此可存 `🐮🍺`、ZWJ 序列、普通文本+Emoji。
- **排序约束**：原始 `py` 按字典序排列；回写工具会自动稳定排序。
- **实机闭环已完成**：替换系统 LEX 后，切换到英文输入法再切回微软拼音，新加入的候选已实际出现；`niubi → 🐮🍺` 验证成功。
